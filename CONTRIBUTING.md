# Contributing

Thanks for your interest in improving fp-conv! This guide covers local
development setup and the project's tooling.

## Setup

Clone the repository and install dependencies (this also links the workspace
packages under `packages/`):

```bash
git clone https://github.com/sw23/fp-conv.git
cd fp-conv
npm install
```

## Common tasks

```bash
# Run the core library / web UI test suite
npm test

# Run the tests for the CLI and MCP workspace packages
npm test --workspaces

# Run tests with coverage (enforces per-file thresholds)
npm run test:coverage

# Lint JavaScript and HTML
npm run lint

# Serve the static web app locally, then open http://localhost:8000
python3 -m http.server
```

## Oracle test vectors

`tests/oracle-vectors.json` holds known-good IEEE 754 values generated by
`tests/oracle-validator.py` (which uses Python's `struct` module as a hardware
oracle). If you change the generator, regenerate and commit the vectors:

```bash
npm run oracle:regen
```

CI regenerates these vectors and fails if the committed file has drifted.
